## 1. 논문이 말하는 것

**질문**: 엔트로피 최소화(EM)는 왜 어떤 shift에서는 잘 되고 어떤 shift에서는 한 클래스로 붕괴하는가.

**(1) 붕괴의 씨앗은 적응 전에 이미 있다: prediction bias (§3.1, Table 1)**
- shift가 오면 feature 군집이 움직여 서로 겹치는데, 분류기의 결정 경계는 그대로다. 그래서 예측 클래스 분포가 한쪽으로 쏠린다.
  이것을 prediction bias라고 부른다(실제 클래스 비율과 예측 클래스 비율의 차이).
- 예 (ResNet50-GN):

| 설정 | 클래스 | 실제 | EM 전 | EM 후 | 결과 |
|---|---|---:|---:|---:|---|
| Camelyon 병원 2→4 | Normal | 49.8% | 62.8% | 52.4% | 안정 |
| Camelyon 병원 2→5 | Normal | 49.6% | 85.0% | 100.0% | 붕괴 |
| ImageNet-C Gaussian noise 3 | 최다 예측 클래스 | 0.1% | 0.2% | 0.3% | 안정 |
| ImageNet-C Fog 5 | Geyser | 0.2% | 25.5% | 99.3% | 붕괴 |

- 주장: 쏠림이 작으면 EM이 안정하고, 적응 전 쏠림이 크면 EM이 그것을 키워 붕괴한다. 쏠림은 붕괴의 부산물이 아니라 원인이다.

**(2) EM이 쏠림을 키우는 이유 (§3.2)**
- TTA는 보통 norm 층 affine만 학습하므로 분류기와 결정 경계는 고정이다. EM은 고정된 경계 안에서 feature를 더 확신하는 쪽으로 민다.
- 엔트로피 손실은 연속이라 가까운 샘플은 비슷한 gradient를 받는다. 즉 EM은 "같은 예측을 받은 무리"를 통째로 조인다(Entropy Enigma의
  군집화 해석과 같은 관점).
- 다른 클래스 샘플이 이미 경계를 넘어 와 섞여 있으면, EM은 그 섞인 덩어리를 한 군집으로 보고 경계 한쪽에서 더 조인다. 애매한
  샘플이 다수 클래스로 더 끌려가고, 다음 step은 더 쏠린 상태에서 시작한다(양의 되먹임).

**(3) 방법: DSBR (§4, 부록 A Algorithm 1)**
- 목표 분포: 예측 클래스마다 같은 무게를 주는 분포 `p*(x) = p(x) / (K · p_Ŷ(ŷ(x)))`.
- 손실: 중요도 재가중으로 `L = (1/B) Σ_i H(f(x_i)) / (K · P̂[ŷ_i])`. 많이 예측된 클래스의 샘플은 가중이 작고, 적게 예측된 클래스의
  샘플은 가중이 크다. 샘플을 버리지 않는다(필터 없음).
- `P̂[k]` = 예측 클래스 빈도의 EMA: `P̂ ← α P̂ + (1−α) · (배치에서 k로 예측된 비율)`, 시작값 1/K, α = 0.9.
  한 배치에서 P̂를 먼저 갱신하고 그 값으로 손실을 계산한다.
- 하이퍼파라미터는 α 하나. Adam(기본 β, weight decay 0), lr은 "Tent의 배치 크기별 기본값".
- 어떤 파라미터를 학습하는지는 명시가 없다("trainable parameters θ̃ ⊂ θ"). Tent와 같은 norm affine으로 읽힌다.

**(4) 실험**
- 의료 4종(WILDS-Camelyon, Histopantum, MammoBench, GliomaMRI), ResNet50-GN과 ViT-B/16, 배치 32, source로 직접 학습한 모델.
  평가는 target의 20% holdout에서 적응이 끝난 뒤의 balanced accuracy(온라인 정확도는 후반 붕괴를 가린다는 이유).

| ∆Average (무적응 대비, pt) | Tent | SAR | ROID | DeYO | DSBR |
|---|---:|---:|---:|---:|---:|
| ResNet | +0.8 | +0.3 | +1.7 | −0.9 | +4.2 |
| ViT | +0.2 | +0.0 | +2.3 | +2.0 | +2.6 |

  Camelyon 20개 병원 쌍 중 Tent는 여러 쌍에서 50%(찍기)로 붕괴하고 DSBR은 붕괴가 없다(Fig. 3, 캡션과 본문 기준).
- ImageNet-C 강도 5, 배치 64, 전체 50,000장에 적응(holdout 없음), 정확도 %:

| 모델 | 방법 | Default | Label shift | Mixed | 배치 1 |
|---|---|---:|---:|---:|---:|
| ResNet50-GN | 무적응 | 31.4 | 31.4 | 31.4 | 31.4 |
| | Tent | 32.2 | 30.3 | 32.1 | 30.8 |
| | SAR | 36.7 | 37.8 | 38.5 | 35.8 |
| | ROID | 46.8 | 2.7 | 37.6 | 0.1 |
| | DeYO | 44.1 | 44.1 | 39.4 | 43.9 |
| | DSBR α=0.99 | 49.7 | 46.8 | 43.0 | 41.6 |
| | DSBR α=0.9 | 48.8 | 38.2 | 41.4 | 38.3 |
| ViT-B/16 | 무적응 | 39.8 | 39.8 | 39.8 | 39.8 |
| | Tent | 51.9 | 53.0 | 33.1 | 51.7 |
| | SAR | 54.2 | 56.2 | 53.7 | 56.2 |
| | ROID | 64.6 | 86.4 | 57.2 | 0.1 |
| | DeYO | 61.8 | 62.4 | 53.6 | 61.8 |
| | DSBR α=0.99 | 64.9 | 56.2 | 60.9 | 58.2 |
| | DSBR α=0.9 | 64.4 | 42.2 | 59.5 | 55.9 |

- EMA의 역할(§5.3): 클래스가 적으면(K=2) 배치 4 이상에서 배치 빈도만으로 충분하다. 클래스가 많으면(K=1000, B=64) EMA가 꼭
  필요하다. 배치 1에서 α=0이면 Tent와 같아진다.
- 부록 E: gradient norm이 큰 샘플이 붕괴를 일으킨다는 SAR의 설명에 반대한다(큰 gradient norm은 붕괴의 결과). 부록 F: 엔트로피
  필터가 듣는 이유는 경계 근처(엔트로피가 높은 곳)에 잘못 넘어온 샘플이 몰려 있어서라고 설명한다.
- 부록 G: ROC-AUC는 어떤 방법으로도 거의 오르지 않는다(+1.0pt 이하). EM이 틀린 샘플에도 확신을 주기 때문이라는 설명.

**저자가 밝힌 한계**: P̂ 추정이 나빠지는 경우, 즉 실제 클래스 비율이 치우친 경우(label shift, α=0.9에서 ViT 42.2로 Tent 53.0보다
낮음)와 배치가 클래스 수에 비해 매우 작은 경우. 균등한 클래스 비율을 가정한 방법이다.

## 2. 우리 연구와의 관계

**겹치는 관찰**
- 우리가 본 "과신은 예측 쏠림과 같이 나온다"(data gaps, scale, motion blur에서 sup_in_r50의 최다 예측 클래스 비율 31–52%)는 이 논문의
  prediction bias와 같은 현상이다. 이 논문은 그것을 EM 붕괴의 원인으로 지목했다.
- 우리 분해로 쓰면: 손상이 만든 공통 이동 c가 logit에 상수 벡터 Wᵀc를 더한다(bias 변화) → 특정 클래스로 예측이 쏠린다. 이 논문은
  같은 것을 "군집이 고정된 경계를 넘는다"고 표현한다. 논문은 feature 쪽 측정(공통 이동 비율, head 방향 에너지)은 하지 않았다.
- 우리 결과 "정렬(align) 후에는 TENT가 안전하다"와도 맞는다. 정렬이 쏠림(Wᵀc)을 먼저 없애기 때문이라고 해석할 수 있다(가설).

**다른 점**

| | DSBR | 우리 |
|---|---|---|
| 쏠림을 다루는 곳 | 손실(예측 클래스별 가중) | head 입력(source 통계로 정렬), flip 필터 |
| 필요한 source 정보 | 없음 | feature 평균·표준편차 |
| 가정 | test의 실제 클래스 비율이 균등 | 배치 통계가 믿을 만함(배치 크기), 공통 이동이 있음 |
| 모델 | source로 끝까지 학습한 분류기 | frozen foundation model + 선형 head |
| 평가 | 적응 후 holdout balanced accuracy | 온라인 정확도 |

**우리 쪽 주의점**
- AID는 클래스당 장수가 다르다(220–420장). 균등 가정에서 약간 벗어난다. RESISC45는 균등(클래스당 700장).
- 우리 stream은 짧다(AID 2,000장 = 31 step, RESISC45 6,300장 = 99 step). 이 논문의 붕괴는 수백~수천 step에서 나온다.
- 우리 평가는 온라인 정확도라, 이 논문이 지적한 "후반 붕괴가 가려지는" 문제가 있을 수 있다.
